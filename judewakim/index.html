SecurityStack

A Python CDK app that ships as one CloudFormation stack.

Custom resources check which services an account already runs and enable only what's missing, so the stack deploys cleanly on real accounts instead of failing on conflicts. EventBridge and Lambda route findings to email. Every push runs tests and a cdk-nag synth in GitHub Actions, and staging deploys through OIDC with no stored keys. The result: GuardDuty, Security Hub, Config, Inspector, Access Analyzer and CloudTrail on in one click, with critical findings and a weekly posture report by email. Includes a free read-only account check.

Python CDK, CloudFormation custom resources, Lambda, EventBridge, SNS, cdk-nag, GitHub Actions with OIDC

Try it live GitHub

S3 Sentry

A containerized scanner that runs on Lambda across AWS accounts.

Packages Prowler as a Lambda container image, run daily by EventBridge. It assumes a read-only role in each account through STS and keeps tenants, findings and an audit log in DynamoDB. Fixes go out as HMAC-signed links with a 48-hour undo. The result: every bucket checked against 14 S3 controls mapped to NIST CSF, with one-click fixes for the riskiest. The live demo scans your own account through a read-only IAM role you deploy and delete.

Python, Docker, Lambda container images, EventBridge, DynamoDB, STS, SSM, SES, CloudFormation

Try it live GitHub

AWS Waste Finder

A serverless multi-region scanner, built with CDK and shipped through CI/CD.

Lambda scans every enabled region through a read-only cross-account role locked to an ExternalId, reading CloudWatch metrics and Compute Optimizer. One failed check, region or account never stops the rest. Results live in DynamoDB and encrypted S3 with short expiry, and GitHub Actions deploys to staging through OIDC. The result: idle NAT gateways, unattached volumes, unused Elastic IPs and seven other kinds of waste, each with a monthly cost and a fix. Runs weekly with an emailed summary, or scan your own account live through a read-only IAM role you deploy and delete.

Python, Lambda, AWS CDK, API Gateway, DynamoDB, CloudFront, EventBridge, SNS, STS, GitHub Actions with OIDC
