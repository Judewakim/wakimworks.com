The Arsenal

A multi-tenant SaaS I build and run in production.

Serves about 30 insurance-agent accounts on AWS Amplify, with Cognito sign-in, Lambda APIs and DynamoDB, tenant data isolated per account and encrypted with KMS. Changes ship through a staging environment and CI before I promote them to production. Includes Stripe billing and Twilio texting.

AWS Amplify, Cognito, Lambda, DynamoDB, KMS, Stripe, Twilio, GitHub Actions

AWS Waste Finder

Scans every region of an AWS account for idle spend.

A serverless scanner deployed with AWS CDK that sweeps every region for idle NAT gateways, unattached volumes, unused Elastic IPs and seven other kinds of waste, then prices each finding and attaches a fix. Rightsizing comes from Compute Optimizer. Runs weekly on EventBridge with an SNS summary, or scans your own account live through a read-only cross-account role you deploy and delete.

Python, Lambda, AWS CDK, API Gateway, DynamoDB, CloudFront, EventBridge, SNS, STS, GitHub Actions with OIDC

Try it live GitHub

SecurityStack

One CloudFormation stack that turns on an account’s security baseline.

Deploys GuardDuty, Security Hub, AWS Config, Inspector, Access Analyzer and CloudTrail in one stack built with Python CDK. Custom resources detect services the account already runs and leave them alone, so it deploys cleanly on real accounts. EventBridge and SNS email critical findings and a weekly posture report. CI runs cdk-nag and deploys through GitHub Actions with OIDC, no stored keys.

Python CDK, CloudFormation custom resources, Lambda, EventBridge, SNS, cdk-nag, GitHub Actions with OIDC

Try it live GitHub

S3 Sentry

Containerized scanner that finds and fixes risky S3 buckets.

Runs 14 Prowler checks against every bucket in an account from a Lambda container image, stores results in DynamoDB, maps each failure to NIST CSF and emails signed one-click fixes. The live demo scans your own account through a read-only cross-account role you deploy and delete.

Python, Docker, Lambda container images, EventBridge, DynamoDB, STS, CloudFormation

Try it live GitHub

SOC 2 Evidence Kit

Collects audit evidence from an AWS account automatically.

Checks an account against 31 SOC 2 controls through a read-only role, maps each result to a Trust Services Criterion, and packages the raw AWS responses with a SHA-256 manifest. Deployable with CloudFormation or Terraform and tested with pytest and moto. Try the sample, or run it in CloudShell and open your own report; nothing leaves your browser.

Python, boto3, STS with External ID, CloudFormation, Terraform, openpyxl, pytest with moto, GitHub Actions
